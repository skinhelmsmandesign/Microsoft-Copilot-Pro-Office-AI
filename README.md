## Usage

1. Download and extract the repository files.
2. Open the `/docs` folder and read the `GettingStarted.md` guide.
3. Choose your desired configuration:
   - **Templates:** Import the document, presentation, and analysis templates from `/templates`.
   - **Scripts:** Run the automation scripts from `/scripts` for workflow optimization and custom GPT creation.
   - **Presets:** Apply the model selection, image creation, and integration presets from `/presets`.
4. Launch Copilot Pro within your Microsoft 365 app and follow the documentation to apply your configurations.
